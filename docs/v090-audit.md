`npm run check` прошёл. Исходный `npm test` дал 18 успешных проверок и один пропущенный браузерный сценарий. В исходном дереве отсутствует `render.yaml`. После первоначального таймаута повторный запрос Render к `/api/health` вернул `401 Unauthorized` и заголовок `X-RPM-Revision` с ревизией `e60929a856d37eb3c8e52bb659c217f269d37354`. `git ls-remote` подтвердил тот же SHA ветки `main` на GitHub. Ответ за аутентификацией не проверен.

`.env` и варианты локальных окружений исключены из Git. В дереве есть ранее отслеживаемые архивные файлы, включая копии серверного и браузерного кода. Требуется проверка истории Git и списка файлов, доступных через статический сервер.

Сессия администратора перепроверяет запись пользователя и привязку устройства. В состоянии исходной ревизии роль владельца зависит от учётной записи администратора, сопоставленной с `OWNER_USER`. Старый вход через Basic Auth использует настроенные сервером учётные данные и отдельное сопоставление с пользователем PostgreSQL. Новые маршруты CRM и структурированного анализа требуют сессию, подтверждённую через БД. Полный аудит существующих маршрутов изменения данных и технических журналов остаётся открытым.
