# Live Assistant v1.0

## Аудит

- `server.js` проверяет устройство и активную лицензию, содержит Gemini-клиент и поиск по источникам RPM.
- `legal-engine.js` проверяет соответствие ссылок и цитат переданным источникам. API дел привязывает записи к аккаунту.
- `public/index.html` содержит рабочее пространство и глобальный поиск. Live Assistant открывается в собственном диалоге.
- Тестовый стенд использует PGlite и Playwright. Доступность браузеров и тестовых зависимостей предстоит проверить.

## Реализация

- `public/live-assistant.*` и `public/index.html` добавляют диалог, диктовку, редактирование, сессии, режимы и RP-фразы.
- `live-assistant.js` использует Gemini из `server.js`, проверку ссылок из `legal-engine.js` и действующие правила доступа.
- Миграция 008 добавляет избранные фразы по аккаунтам и дневные агрегаты без аудио, текста и идентификаторов пользователей. `private/owner.html` выводит метрики.
- Далее — unit, integration и browser tests с подменой Gemini и Speech Recognition.

## Проверки

- `npm run check` и `npm test` с Chrome 157 прошли. 25 тестов, 0 ошибок, 0 пропусков.
- Мобильный сценарий Live также прошёл в Edge 158. В обеих сборках обнаружен браузерный API. Разрешение, остановка и результат проверены с подменой Speech Recognition. Физический микрофон и Opera не проверены.
- На локальном стенде с mock AI серверные замеры трёх режимов составили 34–102 мс, а браузерные замеры краткого режима — 58–63 мс.
- Стенд с PGlite проверил миграцию, доступ по лицензии, недействительные ссылки, отказ анонимным и cross-site запросам, раздельные избранные фразы и дела, агрегаты владельца.
- Внешняя проверка `gemini-3.1-flash-lite` на синтетической ситуации: полный анализ один раз вернул валидный результат за 22,714 с. Попытки в коротких режимах завершились HTTP 503 или таймаутом около 15 с. Диагностическая смена глубины рассуждения и проверка Gemini 3.5 Flash-Lite проблему не устранили.
- Render доступен. До публикации `/api/health` вернул 401 с `X-RPM-Revision: 385b9df67096bbedf2840b74f4897bcaea48fb65`. Публикация требует успешной проверки работоспособности Gemini.

## Публикация

- Изменения проверены через `git diff --cached --check`. В коммит входят только файлы функции, миграция, тесты и этот журнал.
- Следующий этап — успешный внешний замер коротких режимов, затем `git push origin main`, ожидание Render и сравнение `X-RPM-Revision` с опубликованным коммитом.

## Пункт в боковом меню

- В `public/index.html` и `public/rpm-shell.js` добавлен пункт Live Assistant с иконкой микрофона. Он открывает существующий диалог. Быстрый доступ из верхней панели и горячая клавиша сохранены.
- Браузерный сценарий в `tests/workspace-integration.test.mjs` проверяет иконку, закрытие мобильного меню при открытии Live и возврат фокуса после Escape.
- `npm run check`, проверка синтаксиса `public/rpm-shell.js` и все 25 тестов в Chrome прошли.
- Следующий этап публикации указан выше. Повторный внешний замер дал краткий ответ за 2,7 с, а мгновенный режим вернул HTTP 503.

## Подготовка к публикации

- Добавлен прямой вход через `/#live`. Браузерный тест открывает диалог по этому адресу.
- При HTTP 503 или таймауте Gemini мгновенный режим показывает стандартную RP-реплику с явным статусом недоступности Gemini, без правовой оценки и ссылок.
- Миграция 008 добавляет только две таблицы. Интеграционный тест проверяет применение миграций, сохранение пользователей, заказов и лицензий на отдельной базе PGlite.
