RPM Attorney Assistant — пакет изменений для личных дел и резервных копий

Содержимое архива — рабочая копия проекта без .env, .git, node_modules, .neon, IDE-настроек и старых резервных копий.

Установка:
1. Сделай копию своей текущей папки проекта.
2. Распакуй содержимое этого архива в существующую папку RPM_Attorney_Assistant_v070 с заменой файлов.
3. НЕ удаляй и НЕ заменяй свой текущий .env. В архиве его нет намеренно.
4. Не запускай скрипты создания администратора повторно.

Что изменено:
- server.js: дела и резервные копии администратора ограничены user_id; Basic Auth APP_USER получает постоянный ID в rpm_users; старые записи с user_id IS NULL переносятся на QuantumMuse при первом успешном запросе владельца.
- customer-auth-routes.js: защищённые API дел и резервных копий для вошедшего покупателя; операции ограничены ID его сессии.
- customer/account.html: раздел «Мои дела», редактирование, удаление и восстановление резервных копий.

Перенос старых данных не выполнялся из этого архива: он выполнится на сервере после установки кода и первого успешного запроса, аутентифицированного как APP_USER=QuantumMuse. Он переносит только строки rpm_cases и rpm_case_backups, у которых user_id IS NULL, и не меняет уже назначенные записи.

Проверки в пакете:
- node --check server.js
- node --check customer-auth-routes.js
- проверка синтаксиса встроенного JavaScript customer/account.html

Примечание: архив не содержит секретов и не меняет базу данных сам по себе. Перед установкой сохрани копию проекта и базы данных.


ОБНОВЛЕНИЕ 0.7.0 — ПРОФИЛИ, ПАНЕЛЬ ВЛАДЕЛЬЦА И ПАРТНЁРСКИЕ ВЫПЛАТЫ

Перед первым запуском версии 0.7.0 выполните один раз SQL-миграцию:
migrations/001_owner_partners_profiles.sql

Откройте Neon Console → SQL Editor, вставьте содержимое SQL-файла и нажмите Run.
Не запускайте миграцию поверх неизвестной базы без резервной копии. Миграция добавляет поля профиля и игровой банковский счёт партнёра, а также таблицу истории выплат.

После миграции разверните файлы проекта и выполните npm install. Для локальной проверки используйте npm run check, затем npm start.

ЛИЧНЫЙ КАБИНЕТ: /app/account.html
ПАНЕЛЬ ПОМОЩНИКА: /
ПАНЕЛЬ ВЛАДЕЛЬЦА: /owner (доступ только для QuantumMuse через серверную проверку)

Финансовые API /api/owner/* требуют подтверждённого статуса владельца. Разделы сотрудников /api/admin/* требуют администраторской сессии. Покупатели с активной лицензией получают доступ к панели помощника, но не к административным и финансовым API.

Партнёрские выплаты в этой версии только учитываются в системе: приложение не переводит игровую валюту автоматически. Кнопка «Выплатить» фиксирует ручную выплату и закрывает соответствующие ожидающие начисления.


Дополнительно в панели владельца версии 0.7.0 доступны: фильтр финансов по датам, CSV-экспорт заказов и комиссий, уведомления о новых ожидающих заказах и лицензиях с окончанием в ближайшие 7 дней, журнал действий владельца, редактирование и отключение партнёров. Панель обновляет сводку автоматически примерно раз в минуту.

Темы Quantum Purple, Minimal Light, Graphite и Cyber Blue выбираются в профиле и применяются к личному кабинету и панели помощника. Аватар хранится в базе в формате data URL; максимальный размер загружаемого файла — 500 КБ.


ДОПОЛНЕНИЕ К ИСПРАВЛЕННОМУ АРХИВУ:
